# データベーススペシャリスト 過去問特訓

IPAで公開されている2009〜2025年度（17年分）のデータベーススペシャリスト試験の非公式学習サイト。

公開サイト：https://db-enshushitsu.pages.dev/

ID・パスワードでログインして解答・採点結果を保存できます。メールアドレスは不要です。パスワードは12文字以上。メールによる復旧はありません。

## 内容
- 午前Ⅱ：各年度25問、合計425問、選択式の解答と公式解答による自動採点（1問4点）。
- 午後Ⅰ・Ⅱ：合計85問、設問・小問・空欄記号ごとの1668項目を用意。
- 1208項目に公式解答例との自動照合。ア・イ・aなどを個別入力し、個別または問題全体で採点。
- 460項目の図・関係スキーマ・複雑な表等は公式解答例による自己照合。記述・SQLも一致しないときは要確認として自己評価できる。
- 公式PDF136点を収録。問題・解答例等の出典は画面と sources.json に記載。
- ゲストはメモリ内のみ。ID・パスワードでログインすると解答・採点結果をCloudflare D1へ自動保存。メール不要。公開設定はDEPLOY.md参照。
- 独自の詳細解説は未収録。午後の自己採点は小問別配点非公開のため目安。

## 午後の採点範囲
カラム名は全角・半角、空白、読点・カンマ・改行の区切り、並び順を正規化して比較。欠落・余分な列・重複は不一致。公式解答例にある角括弧は入力不要だが、中の列名は照合対象に含む。主キー・外部キーの下線は自動判定しない。

SQLは字句単位で空白とキーワードの大文字・小文字を吸収し、文字列リテラルの大文字・小文字と列の並び順を保持。SQLの意味的同値性の判定・実行はしない。文章は公式解答例の複数候補との正規化後の一致のみ判定し、別表現は不正解と断定せず「要確認」とする。

2025年度午後Ⅱ問2の「基準在庫数」は公式備考に従い、キ・ケのいずれかへの記入を両欄で照合する。一致数は本試験の点数に換算しない。自己評価の正解数は自動一致数と別表示。

過去年度データは dist/archive-data.js、2025年度の午後データは dist/pm-data.js、照合ロジックは dist/grading.js。検証は `node tests/grading.cjs` で実行。

## 実行

## 回答履歴・成績
ログイン後の「回答履歴・成績」から17年度の最新保存結果を一覧表示します。午前の回答・正誤・未採点、午後の入力数・自動一致・自己評価・自己採点を確認できます。過去の全受験回を時系列に蓄積する方式ではありません。問題画面から移動する前に保存を完了し、保存失敗や競合中は移動を止めます。

サイトUIはBIZ UDPGothicを同梱して配信します。フォントのライセンスと配布元はdist/fonts/を参照してください。
